01 — Problem
점주가 매일 겪는 4가지 문제

📋 느린 혼잡도 파악

CCTV 영상을 직접 보면서 바쁜 시간대를 파악하는 방식은 너무 느리고, 실시간 운영 판단에 쓰기 어렵습니다.

👥 피크타임 인력 부족

손님이 몰리는 시간대에 직원이 부족하다는 것을 뒤늦게 알아 고객 서비스 품질이 떨어집니다.

📊 직관에만 의존하는 근무표

경험과 감으로 근무표를 짜다 보면 어떤 날은 인력이 남고, 어떤 날은 부족한 비효율이 반복됩니다.

💸 과도한 인건비 또는 서비스 저하

한산한 시간에도 풀 인원을 배치하거나, 바쁜 시간에 인원이 모자라는 양쪽 문제가 동시에 발생합니다.

08 — Stability
운영 중 장애에도 데이터가 유실되지 않습니다

🔄 비동기 전송 분리

Spring Boot 응답 지연이 AI 추론 흐름을 막지 않도록 내부 큐와 별도의 쓰레드를 두어 속도 저하를 방지합니다.

💾 로컬 Outbox Queue

무거운 외부 MQ 시스템 없이 SQLite로 구현하여, 서버가 재시작되어도 전송하지 못한 데이터가 안전하게 보존됩니다. 최대 재시도 이후에는 FAILED 상태와 실패 payload 로그를 남깁니다.

⚡ LLM Fallback (대비책)

외부 AI(OpenAI 등) 통신에 장애가 생겨도, 시스템 내부에 설정된 룰(Rule) 기반 문장 생성기가 즉시 대신 작동합니다.
