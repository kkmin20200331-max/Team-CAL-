# ShiftOps AI Figma 화면 설계서
## Harness / GPS 제외 + 추가 기능 반영 버전

---

## 0. 이번 버전 설계 기준

이번 Figma 설계는 기존 ShiftOps AI 기획에서 **Harness와 GPS 기능을 제외**하고, 실제 발표와 프로토타입 시연에 필요한 화면 중심으로 재구성한다.

### 제외 항목
- Harness CI/CD 관리 화면
- Harness Feature Flag 화면
- GPS 기반 출퇴근 인증
- GPS 위치 추적
- 지도 기반 출퇴근 위치 확인

### 유지 및 강화 항목
- 고정 근무 기반 근무표 자동 생성
- 날짜별 / 시간대별 근무표 확인
- 겹치는 시간대 상세 확인
- 휴무 신청 및 대타 자동 모집
- 대타 인센티브 점수
- QR 기반 출퇴근 인증
- 지점별 관리
- 연락처 기반 직원 등록
- 게시판
- 실시간 급여 / 주급 신청
- 보건증 OCR
- 근로계약서 OCR / 이미지 복원
- 분실물 공유
- 주야 모드
- 언어 설정
- OpenCV 기반 고객 분석
- AI 운영 추천

# 1. 전체 서비스 구조

## 1.1 서비스명

**ShiftOps AI**

### 한 줄 설명
> 알바 근무표, 대타 모집, 급여, 게시판, 문서 관리, CCTV 고객 분석을 한 번에 처리하는 AI 기반 매장 운영 플랫폼

---

## 1.2 핵심 사용자

### 관리자 / 점주
- 여러 지점을 관리한다.
- 주간 근무표를 작성한다.
- 휴무 신청과 대타 요청을 승인한다.
- 시간대별 근무 인원과 고객 수를 비교한다.
- 급여, 주급 신청, 보건증, 근로계약서를 관리한다.
- CCTV 기반 고객 분석 결과를 확인한다.
- AI 추천을 통해 인력 배치, 메뉴, 좌석, 재고, 이벤트 전략을 세운다.

### 직원 / 아르바이트생
- 내 근무표를 확인한다.
- QR로 출퇴근한다.
- 휴무 신청을 한다.
- 대타 요청을 받고 지원한다.
- 예상 급여와 주급 신청 상태를 확인한다.
- 공지사항, 신메뉴, 이벤트, 레시피, 메뉴얼을 확인한다.
- 보건증을 업로드하고 근로계약서를 확인한다.

### 다지점 관리자
- 컴포즈 미금점, 수내점, 동천점을 지점별로 관리한다.
- 지점별 근무 인원, 혼잡도, 대타 발생, 인건비를 비교한다.

# 3. 관리자 웹 화면 설계

---

## 화면 1. 관리자 로그인

### 목적
관리자가 서비스에 접속하는 첫 화면.

### 화면 구성
- ShiftOps AI 로고
- 아이디 입력
- 비밀번호 입력
- 로그인 버튼
- 언어 선택 버튼
  - 한국어
  - English
  - 日本語
- 주야 모드 토글

### 클릭 흐름
- 로그인 성공 → 지점 선택 화면
- 언어 변경 → UI 언어 변경
- 주야 모드 토글 → 라이트 / 다크 모드 전환

---

## 화면 2. 지점 선택

### 목적
관리자가 관리할 지점을 선택한다.

### 지점 카드
- 컴포즈 미금점
- 컴포즈 수내점
- 컴포즈 동천점

### 지점 카드 정보
- 오늘 근무 인원
- 현재 고객 수
- 현재 혼잡도
- 대타 필요 건수
- 휴무 신청 대기 건수
- 보건증 만료 예정자
- 공지 미확인 직원 수

### 버튼
- 지점 상세 보기
- 전체 지점 통합 보기

### 클릭 흐름
- 특정 지점 클릭 → 해당 지점 메인 대시보드
- 전체 지점 통합 보기 클릭 → 다지점 통합 대시보드

---

## 화면 3. 관리자 메인 대시보드

### 목적
오늘 매장 운영 상태를 한눈에 확인한다.

### 상단 요약 카드
1. 오늘 근무 인원
2. 현재 매장 인원
3. 현재 혼잡도
4. 대타 필요 건수
5. 휴무 신청 대기
6. 오늘 예상 인건비
7. 보건증 만료 예정
8. 주급 신청 대기

### 중앙 차트
- 실시간 매장 인원 추이
- 시간대별 고객 수
- 시간대별 근무 인원
- 고객 수 대비 근무 인원 적정성 그래프

### 오른쪽 알림 패널
- 오늘의 운영 리스크
- 대타 필요 알림
- 근무표 작성 알림
- 보건증 만료 알림
- 주급 신청 알림
- 신규 비공개 건의사항 알림

### 하단 영역
- 오늘 근무자 목록
- 오늘 체크리스트 진행률
- AI 추천 카드

### AI 추천 카드 예시
> 금요일 18:00~20:00 고객 수가 평균보다 높습니다.  
> 해당 시간대 대타 1명 추가 배치를 추천합니다.

---

## 화면 4. 다지점 통합 대시보드

### 목적
여러 지점의 운영 상태를 비교한다.

### 주요 구성
- 지점별 운영 카드
- 지점별 고객 수 비교 차트
- 지점별 혼잡도 비교 차트
- 지점별 근무 인원 비교
- 지점별 대타 발생 횟수
- 지점별 예상 인건비
- 지점별 보건증 만료 예정자

### 비교 항목
- 현재 고객 수
- 오늘 평균 혼잡도
- 피크타임
- 오늘 근무 인원
- 대타 필요 건수
- 휴무 신청 대기
- 게시판 미확인 직원 수

### 클릭 흐름
- 지점 카드 클릭 → 해당 지점 상세 대시보드
- 혼잡도 차트 클릭 → AI 고객 분석 화면

# 4. 근무표 관리 화면

---

## 화면 5. 주간 근무표

### 목적
한 주의 근무표를 전체적으로 확인하고 수정한다.

### 화면 구성
- 지점 선택 드롭다운
- 날짜 선택
- 주간 / 월간 / 일간 보기 전환
- 직원 검색
- 직원 등급 필터
  - 신입
  - 일반
  - 마감 가능자
  - 관리자
- 타임테이블 그리드

### 타임테이블 표현
- 가로축: 날짜 / 요일
- 세로축: 직원명
- 근무 시간: 컬러 블록
- 대타 필요: 빨간 점선 블록
- 휴무 신청 중: 노란 배지
- 마감 가능자: M 배지
- 신입: N 배지
- 운영 리스크: 경고 아이콘

### 표시 상태
- 정상 근무
- 대타 필요
- 휴무 신청
- 대타 승인 대기
- 대체 완료
- 신입 단독 근무 위험
- 마감 가능자 없음
- 근무 인원 부족
- 근무 인원 과다

### 클릭 흐름
- 날짜 클릭 → 일간 타임표
- 근무 블록 클릭 → 근무 상세 모달
- 대타 필요 블록 클릭 → 대타 모집 관리
- 경고 아이콘 클릭 → 리스크 상세

---

## 화면 6. 일간 타임표

### 목적
특정 날짜의 근무 흐름을 시간대별로 자세히 확인한다.

### 진입 방식
주간 근무표에서 특정 날짜를 클릭한다.

### 화면 구성
- 선택 날짜
- 지점명
- 시간대별 근무 인원 그래프
- 직원별 타임라인
- 겹치는 시간대 강조
- 공백 시간대 강조
- 예상 고객 수 표시
- 예상 인건비 표시
- AI 인력 판단 배지

### 예시 데이터
| 시간 | 근무 인원 | 예상 고객 수 | 상태 |
|---|---:|---:|---|
| 09:00~12:00 | 1명 | 8명 | 부족 위험 |
| 12:00~15:00 | 3명 | 28명 | 적정 |
| 15:00~17:00 | 2명 | 15명 | 정상 |
| 17:00~22:00 | 2명 | 25명 | 마감 가능자 포함 |

### 클릭 흐름
- 겹치는 시간대 클릭 → 겹치는 시간대 상세 모달
- 공백 시간대 클릭 → 대타 모집 관리
- 직원명 클릭 → 직원 상세
- 시간대별 고객 수 클릭 → 고객 분석 상세

---

## 화면 7. 겹치는 시간대 상세 모달

### 목적
특정 시간대에 누가 함께 근무하는지, 인력이 과한지 부족한지 확인한다.

### 화면 구성
- 선택 시간대
- 겹치는 근무자 목록
- 직원별 등급
- 총 근무 인원
- 해당 시간 평균 고객 수
- 혼잡도
- 인력 판단 결과
  - 부족
  - 적정
  - 과다
- AI 추천

### AI 추천 예시
- 현재 인력 유지
- 1명 추가 배치 권장
- 1명 감축 가능
- 마감 가능자 추가 필요
- 신입 단독 근무 방지 필요

### 버튼
- 근무 시간 수정
- 직원 교체
- 대타 모집
- 알림 보내기
- 닫기

- 근무 날짜
- 계획 근무 시간
- 실제 출퇴근 시간
- 근무 상태
- 직원 등급
- 시급
- 예상 급여
- 체크리스트 상태

### 버튼
- 시간 수정
- 휴무 처리
- 대타 전환
- 직원에게 알림
- 저장

---

## 화면 9. 고정 근무 설정

### 목적
직원별 고정 근무 패턴을 등록한다.

### 화면 구성
- 직원 선택
- 지점 선택
- 요일 선택
- 시작 시간
- 종료 시간
- 반복 기간
- 예외 날짜 설정
- 저장 버튼

### 기능
- 고정 근무 자동 생성
- 특정 날짜만 예외 처리
- 고정 근무자가 빠지는 경우 대타 슬롯 자동 생성
- 직원별 고정 근무 목록 표시

### 예시
- 김OO / 월·수 / 18:00~22:00 / 컴포즈 미금점
- 이OO / 토·일 / 12:00~18:00 / 컴포즈 수내점

## 화면 10. 주간 근무표 작성 알림 설정

### 목적
관리자가 매주 근무표 작성을 잊지 않도록 알림을 설정한다.

### 화면 구성
- 알림 요일 선택
- 알림 시간 선택
- 대상 지점 선택
- 담당 운영자 선택
- 미작성 시 재알림 여부
- 직원 자동 공지 여부

### 알림 상태
- 작성 완료
- 작성 전
- 마감 임박
- 미작성

### 알림 문구 예시
> 이번 주 컴포즈 미금점 근무표가 아직 작성되지 않았습니다.  
> 오늘 18시까지 등록해주세요.

# 5. 휴무 / 대타 관리 화면

---

## 화면 11. 휴무 신청 관리

### 목적
직원들이 신청한 휴무를 관리자가 승인하거나 반려한다.

# 17. 최종 요약

이번 Figma 설계의 핵심은 다음과 같다.

1. 근무표를 날짜별 / 시간대별로 볼 수 있다.
2. 겹치는 시간대와 비는 시간대를 클릭해서 상세 확인할 수 있다.
3. 휴무가 생기면 대타 모집으로 자연스럽게 연결된다.
4. QR 기반 출퇴근으로 GPS 없이 근태를 기록한다.
5. 급여와 주급 신청이 근무 기록과 연결된다.
6. 보건증과 근로계약서를 OCR로 관리한다.
7. 게시판으로 공지, 신메뉴, 이벤트, 메뉴얼, 레시피, 분실물을 관리한다.
8. OpenCV 고객 분석으로 실제 매장 혼잡도와 근무 인원을 비교한다.
9. AI가 인력 배치, 메뉴, 좌석, 이벤트, 유휴 업무를 추천한다.
10. 지점별 관리, 주야 모드, 언어 설정까지 포함해 실제 서비스처럼 보이게 만든다.

발표에서는 다음 문장으로 정리하면 좋다.

> 이번 MVP에서는 Harness와 GPS 기능은 제외했습니다.  
> 대신 실제 매장 운영에 바로 필요한 QR 출퇴근, 근무표 자동화, 대타 모집, 급여 계산, 게시판, 문서 OCR, 고객 분석 기능에 집중했습니다.
