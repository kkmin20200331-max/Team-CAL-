# Team-CAL Frontend

React/Vite admin web application.

## Run Locally

```powershell
npm install
npm run dev
```

Local `.env`:

```env
VITE_API_BASE_URL=http://localhost:8080/api
```

## Build

```powershell
npm run build
```

For production deployment, use:

```env
VITE_API_BASE_URL=/api
```

See [../docs](../docs/README.md) for deployment and troubleshooting.
