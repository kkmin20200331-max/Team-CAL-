# 💻 나의 역할 및 기여 상세 (My Role & Contributions)

저는 Team-CAL 프로젝트의 프론트엔드 개발자로서, 앱의 핵심 기능 구현과 사용자 경험 향상에 기여했습니다. 저의 주요 역할은 다음과 같습니다.

---

### 1. 관리자-직원 간 역할 분리 아키텍처 설계 및 구현

**목표**: 관리자와 직원의 사용 맥락이 완전히 다르다는 점에 착안하여, 단일 앱 내에서 두 사용자에게 각기 다른 경험과 기능을 제공하는 유연한 구조를 만드는 것이었습니다.

**수행 내용**:
- **전역 상태 관리**: `AppContext`를 생성하여 로그인 시 사용자의 정보(특히 `role`)를 전역적으로 관리했습니다.
- **동적 UI 렌더링**: `userInfo.role` 값에 따라 화면의 특정 섹션이나 메뉴가 조건부로 렌더링되도록 구현했습니다. 예를 들어, `MyPageScreen.tsx`에서 관리자에게는 '직원 관리' 메뉴를, 직원에게는 '나의 급여' 메뉴를 보여주는 로직을 작성했습니다.
- **API 접근 제어**: 프론트엔드 단에서부터 역할에 맞지 않는 API 호출을 방지하는 로직을 추가하여 안정성을 높였습니다.

**결과**: 하나의 코드 베이스로 두 개의 다른 앱처럼 동작하는 효율적인 구조를 구축했습니다. 이는 코드 중복을 최소화하고 유지보수성을 크게 향상시켰습니다.

---

### 2. 문서 관리 시스템 구축 (보건증/근로계약서)

**목표**: 오프라인으로 관리되던 보건증, 근로계약서와 같은 필수 서류를 디지털화하여 관리자와 직원의 편의성을 증대시키는 것이었습니다.

**수행 내용**:
- **API 설계 및 연동**: 백엔드 개발자와 협력하여 문서 업로드 및 조회를 위한 RESTful API 명세를 정의하고, `api/auth.ts`에 `Axios`를 사용한 API 함수(`uploadHealthCertificateAPI`, `getHealthCertificatesAPI` 등)를 구현했습니다.
- **파일 업로드 구현**: `expo-image-picker`를 사용하여 사용자가 갤러리에서 이미지를 선택할 수 있게 하고, `FormData` 객체를 사용하여 선택된 파일을 백엔드 서버(Supabase Storage)로 전송하는 로직을 `HealthCertScreen.tsx`과 `ContractScreen.tsx`에 구현했습니다.
- **UI/UX 디자인**: 직원이 문서를 업로드하면 '승인 대기' 상태로 표시되고, 관리자가 이를 확인하는 과정을 직관적으로 이해할 수 있도록 UI를 설계했습니다.

**결과**: 번거로운 서류 작업을 모바일 앱으로 완결할 수 있는 편리한 시스템을 구축하여, 매장 운영의 효율성을 실질적으로 개선했습니다.

---

### 3. 앱 전체 다크 모드 UI 리팩토링

**목표**: 초기 개발 단계에서 일관성 없이 적용되었던 다크 모드 스타일을 전면 재검토하고, 모든 화면에서 완벽하고 일관된 사용자 경험을 제공하는 것이었습니다.

**수행 내용**:
- **중앙 테마 시스템 구축**: `ThemeContext.tsx`에 앱에서 사용되는 모든 색상을 의미 기반(semantic) 변수(예: `primary`, `text`, `border`, `sunday`)로 정의했습니다. 라이트/다크 모드에 따라 이 변수들의 실제 색상 값이 동적으로 변경되도록 설계했습니다.
- **전역 리팩토링**: 프로젝트 내의 **모든 `StyleSheet`**를 검토하여, 하드코딩된 색상 코드(예: `'#000'`, `'white'`)를 `colors.text`, `colors.card`와 같은 테마 변수로 100% 교체했습니다.
- **코드 구조 개선**: 각 컴포넌트에 불필요하게 전달되던 `isDarkMode` prop을 제거하고, 모든 컴포넌트가 `useTheme` 훅을 통해 테마 색상을 직접 사용하도록 구조를 통일하여 코드의 가독성과 유지보수성을 향상시켰습니다.

**결과**: 전문적인 상용 앱 수준의 완성도 높은 다크 모드 UI를 구현했습니다. 이는 사용자에게 시각적 편안함을 제공하고, 야간 근무가 잦은 매장 환경에서의 사용성을 크게 높였습니다.
