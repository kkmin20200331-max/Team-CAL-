# 💻 나의 역할 및 기여 상세 (My Role & Contributions)

저는 Team-CAL 프로젝트의 프론트엔드 개발자로서, 앱의 핵심 기능 구현과 사용자 경험 향상, 그리고 안정적인 개발 환경 구축에 기여했습니다. 저의 주요 역할은 다음과 같습니다.

---

### 1. 핵심 기능 구현 및 연동 (회원가입, 직원/스케줄 관리)

**목표**: 앱의 근간이 되는 사용자 가입, 직원 관리, 스케줄 관리 기능을 백엔드 API와 연동하여 실제 동작 가능한 수준으로 완성하는 것이었습니다.

**수행 내용**:
- **API 명세 동기화**: 백엔드 Java 코드를 직접 분석하여 `@RequestMapping`, `@RequestParam` 등 어노테이션 기반의 API 명세를 파악했습니다. 이를 바탕으로 프론트엔드의 `auth.ts`에 정의된 모든 API 호출 함수를 실제 서버와 100% 일치하도록 리팩토링하여, 데이터 통신의 신뢰성을 확보하고 잠재적인 런타임 오류를 근절했습니다.
- **데이터 정합성 문제 해결**: 직원 회원가입 과정에서 반복적으로 발생하던 500 에러(ORA-00001, ORA-02291, ORA-12899 등)의 원인을 백엔드 로그와 API 호출 데이터를 비교 분석하여 해결했습니다. 프론트엔드의 중복 API 호출로 인한 '유령 데이터' 생성 문제, DB 제약조건과 맞지 않는 데이터 형식(ID 길이, 필수 값 누락) 등을 찾아내고 수정하여 데이터 무결성을 확보했습니다.
- **사용자 흐름(User Flow) 구현**: '직원 가입 → 관리자 승인 → 직원 로그인'으로 이어지는 전체 온보딩 플로우와, '스케줄 생성 → 조회 → 수정/삭제'의 핵심 관리 기능을 API와 연동하여 완성했습니다. 이 과정에서 역할(`ADMIN`/`STAFF`)에 따라 다른 UI와 API를 호출하는 분기 로직을 구현하여 사용자 경험을 최적화했습니다.

**결과**: 앱의 가장 핵심적인 기능들을 안정적으로 동작하도록 구현했으며, 복잡한 데이터베이스 에러를 체계적으로 분석하고 해결하는 문제 해결 능력을 입증했습니다.

---

### 2. 안정적인 개발 아키텍처 설계 및 문제 해결

**목표**: 단순히 기능을 구현하는 것을 넘어, 발생할 수 있는 오류를 사전에 방지하고, 복잡한 개발 환경 문제를 해결하여 프로젝트의 안정성과 개발 효율성을 높이는 것이었습니다.

**수행 내용**:
- **네트워크 연결 문제 해결**: 외부 서비스(LINE) 연동 테스트 중, 로컬 개발 서버와 외부 인터넷 간의 연결이 실패하는 문제를 겪었습니다. `cloudflared`의 네트워크 호환성 문제를 체계적인 테스트(방화벽, 백신, 실행 순서, IP 직접 사용 등)를 통해 분석하고, 대안 솔루션으로 `ngrok`을 도입하여 안정적인 로컬 개발 및 테스트 환경을 성공적으로 구축했습니다.
- **중앙화된 테마 시스템 구축**: `ThemeContext.tsx`에 앱에서 사용되는 모든 색상을 의미 기반(semantic) 변수(예: `primary`, `text`, `border`)로 정의했습니다. 이를 통해 다크 모드 UI의 일관성을 확보하고, 향후 디자인 변경 시 유지보수 비용을 극적으로 절감할 수 있는 구조를 설계했습니다.

**결과**: 기술적인 문제 해결 능력을 바탕으로 프로젝트의 기술적 부채를 줄이고, 동료 개발자들이 신뢰할 수 있는 안정적인 개발 기반을 마련했습니다.

---

### 3. 앱 전체 다크 모드 UI 리팩토링

**목표**: 초기 개발 단계에서 일관성 없이 적용되었던 다크 모드 스타일을 전면 재검토하고, 모든 화면에서 완벽하고 일관된 사용자 경험을 제공하는 것이었습니다.

**수행 내용**:
- **전역 리팩토링**: 프로젝트 내의 **모든 `StyleSheet`**를 검토하여, 하드코딩된 색상 코드(예: `'#000'`, `'white'`)를 `colors.text`, `colors.card`와 같은 테마 변수로 100% 교체했습니다.
- **코드 구조 개선**: 각 컴포넌트에 불필요하게 전달되던 `isDarkMode` prop을 제거하고, 모든 컴포넌트가 `useTheme` 훅을 통해 테마 색상을 직접 사용하도록 구조를 통일하여 코드의 가독성과 유지보수성을 향상시켰습니다.

**결과**: 전문적인 상용 앱 수준의 완성도 높은 다크 모드 UI를 구현했습니다. 이는 사용자에게 시각적 편안함을 제공하고, 야간 근무가 잦은 매장 환경에서의 사용성을 크게 높였습니다.
