# 🚀 Team-CAL: 스마트 매장 관리 앱 (포트폴리오 발표 자료)

## 1. 프로젝트 개요

**Team-CAL**은 카페, 음식점 등 소규모 매장 운영의 효율성을 극대화하기 위해 설계된 **올인원 모바일 매장 관리 솔루션**입니다. 점주(관리자)와 직원(스태프)의 역할을 구분하여, 각 사용자에게 최적화된 기능을 제공함으로써 복잡한 매장 관리를 간소화하고 커뮤니케이션을 활성화하는 것을 목표로 합니다.

---

## 3. 기술 스택 (Tech Stack)

- **프론트엔드**: `React Native`, `Expo`, `TypeScript`
- **상태 관리**: `React Context API`
- **백엔드 연동**: `Axios`
- **개발 환경**: `ngrok`을 활용한 터널링으로 외부 서비스(LINE)와 로컬 개발 서버 간의 안정적인 연동 환경 구축
- **UI/UX**: 다크 모드를 완벽 지원하는 동적 테마 시스템 구축
- **데이터베이스**: `Oracle DB`

---

## 4. 나의 역할 및 기여 (My Role & Contribution)

프로젝트의 **프론트엔드 개발**을 담당했으며, 특히 **사용자 경험(UX) 개선과 안정적인 개발 아키텍처 설계**에 중점을 두었습니다.

1.  **핵심 기능 연동 및 안정화 (회원가입, 직원/스케줄 관리)**:
    - **API 명세 동기화**: 백엔드 Java 코드를 직접 분석하여 API 명세를 파악하고, 프론트엔드의 모든 API 호출 함수를 실제 서버와 100% 일치하도록 리팩토링하여 통신 오류를 사전에 방지했습니다.
    - **데이터 정합성 문제 해결**: 회원가입 플로우에서 발생하는 500 에러의 원인이 프론트엔드의 중복 API 호출로 인한 '유령 데이터' 생성 때문임을 밝혀내고, API 호출 로직을 백엔드 트랜잭션에 맞게 단일화하여 데이터 무결성 문제를 해결했습니다.
    - **사용자 흐름 구현**: '직원 가입 → 관리자 승인 → 직원 로그인'으로 이어지는 전체 온보딩 플로우와, '스케줄 생성 → 조회 → 수정/삭제'의 핵심 관리 기능을 API와 연동하여 완성했습니다.

2.  **안정적인 개발 환경 구축 및 네트워크 문제 해결**:
    - `cloudflared`의 네트워크 호환성 문제를 체계적으로 분석하고, 대안으로 `ngrok`을 도입하여 외부 서비스(LINE)와 로컬 서버 간의 안정적인 연동 테스트 환경을 성공적으로 구축했습니다.

3.  **다크 모드 UI 전체 리팩토링 및 안정화**:
    - 산재해 있던 하드코딩된 색상 값을 제거하고, `ThemeContext`를 활용한 **중앙화된 테마 시스템**을 구축했습니다.
    - 앱의 모든 화면과 컴포넌트에 일관된 다크 모드 경험을 제공하여 시각적 완성도와 사용자 편의성을 크게 향상시켰습니다. (자세한 내용은 '트러블 슈팅' 섹션 참고)
